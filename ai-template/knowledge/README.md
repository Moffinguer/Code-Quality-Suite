# Project knowledge

Plain Markdown (Obsidian-compatible vault; Basic Memory can expose it to every agent through
MCP). Agents read and update it through the skills in `.agents/skills/`.

- `norms/` the organisation's norms map: `norms/INDEX.md`, one note per norm in `norms/norms/`,
  originals in `norms/sources/`, new documents in `norms/inbox/`, rule proposals in
  `norms/proposals/`.
- `recipes/` notes and assets used by the recipe skills (templates, examples).
- `lessons/` lessons learned (`INDEX.md` + one note each).
- `decisions/` architecture decision records.
