# Code of conduct

<!-- Convention: Contributor Covenant 2.1 (https://www.contributor-covenant.org/). -->

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Spanish translation:
<https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/>.

## In short

- Be respectful and constructive; criticise code and decisions, never people.
- No harassment, discrimination or personal attacks, in any channel of the project.
- Maintainers may edit or remove contributions that break these rules and may restrict access
  temporarily or permanently.

## Reporting

Write to the maintainer listed in [MAINTAINERS.md](MAINTAINERS.md). Reports are handled
confidentially.
